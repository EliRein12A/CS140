CSS Grid

The difference between grid and flex is grid is two dimensional, and grid determines the size of the kids. Flex is the opposite, the kids determine their size and they tell the parent that that then lay the kid out. Professor Slade likes flex a lot better. Flex makes it come out a lot easier for mobile and laptops.

The parent decides where the child goes in a grid. However in Flex, it allows the kids to decide their sizes. With the columns the parent tag includes and decides where all of the kids are displayed.
