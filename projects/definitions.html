ASCII and Unicode

ASCII and Unicode are character encoding standards and they are the most used across the world. ASCII is used for electronic communication and assigns the English characters to number forms. Meanwhile, Unicode defines every character in every language and assigns them a unique number.

What is UTF-8?

8-bit Unicode Transformation Format translates text into what the computer is able to read and process into data. UTF-8 is also compatible with ASCII because it's 128 characters match each other making it easy to use together. UTF-8 is significant because it covers almost all written world languages meaning that anyone and everyone can use it!

What is a URL?

A URL otherwise known as the Uniform Resource Locator is the address used to go to a webpage, file, or other resource on the web. The URL has a protocol which tells the browser how to connect to the page, the domain name is the name of the website you're on, and the path points to exact page you're going to. The URL is shareable and is how you can access a page and have others access a page too!

What is Domain Name?

The domain name is the digital address on the internet for your website. If people type the digital address into the web they will find your page. The domain name is also simply named. Meaning that it's not listed as long numbers or random letters, but, as something you can easily access

What is HTTP?

HTTP also known as Hypertext Transfer Protocol is what loads webpages utilizing hypertext links. To go into detail, it is an application layer that moves info between devices on the internet. It sets rules that the computer is able pass back and forth on the internet

What is HTTPS?

HTTPS also known as Hypertext Transfer Protocol Secure which is the secure version of HTTP that sends data between a website and a browser. HTTPS encrypts data making it unreadable which helps to boost security of transfering data. This is very important if someone were to make a very confidential transaction such as making payments to a bank.

What is an IP address?

An IP address, also known as an Internet Protocol address is a series of numbers that every device connected to the internet has. It helps the computer know where to send information and to who, kind of like mailing a letter to someone. There are also different types of IP addresses, such as public IP addresses and private IP addresses.

What is DNS?

DNS also known as Domain Name System is known as the phonebook across the internet. We can access different sites on the internet without having to memorize IP addresses because DNS translates domain names to the IP address. DNS translates the hostname on our computers into a friendly IP address making it very easy to get to destinations. For example, like going to Pokemon.com.

What is W3C Recommendation?

W3C Recommendations are the standards of web development. These standards are not legally enforced but they stand as a best practice on the internet to help everyone. The value of these recommendations lie in the fact that if you follow them, they ensure an accessible web and that if you create a web, that web will work with all other webs.
